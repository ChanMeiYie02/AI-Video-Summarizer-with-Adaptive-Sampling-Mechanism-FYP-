# Summary of Video Summarization Benchmark Categories & Details

This document provides a complete reference guide for the **TVSum50** and **VT-SSum** datasets, outlining their distinct categories, metadata structures, and research contexts.

---

## 1. TVSum50 (Title-based Video Summarization)

The **TVSum50** dataset consists of 50 web videos (sought from YouTube) categorized into **10 distinct event-based categories** based on the TRECVid Multimedia Event Detection (MED) task. Each category contains exactly 5 videos.

### TVSum50 Distinct Categories Table

| Category Code | Event/Category Name | Genre / Topic Context | Annotation Details |
|:---:|:---|:---|:---|
| **VT** | Changing Vehicle Tire | How-to / Instructional tutorial | Shot-level importance scores annotated by 20 different humans |
| **VU** | Getting Vehicle Unstuck | Action / Reality / Outdoor vlog | Shot-level importance scores annotated by 20 different humans |
| **GA** | Grooming an Animal | Instructional / Vlog / How-to | Shot-level importance scores annotated by 20 different humans |
| **MS** | Making Sandwich | Cooking tutorial / How-to | Shot-level importance scores annotated by 20 different humans |
| **PK** | Parkour | Sports / Action / Urban stunt | Shot-level importance scores annotated by 20 different humans |
| **PR** | Parade | Event / News / Public gathering | Shot-level importance scores annotated by 20 different humans |
| **FM** | Flash Mob Gathering | Event / Entertainment / Crowd dance | Shot-level importance scores annotated by 20 different humans |
| **BK** | BeeKeeping | Documentary / Educational vlog | Shot-level importance scores annotated by 20 different humans |
| **BT** | Attempting Bike Tricks | Sports / Stunts / Stunt compilation | Shot-level importance scores annotated by 20 different humans |
| **DS** | Dog Show | Competition / Animal performance | Shot-level importance scores annotated by 20 different humans |

### TVSum50 Dataset Specifications
*   **Total Videos:** 50
*   **Video Format:** Raw `.mp4` video files + YouTube URL mappings
*   **Target Modality:** Multi-modality (Vision features + audio tracks)
*   **Ground Truth:** Shot-level importance scores ($1$ to $5$) generated by 20 Amazon Mechanical Turk crowd-workers per video.

## 2. VT-SSum (Video Transcript Segmentation & Summarization)

The **VT-SSum** dataset (Lv et al., 2021) is a large-scale spoken language summarization benchmark. Instead of YouTube clips, it is built from academic talks and educational video recordings sourced from **VideoLectures.NET**.

### VT-SSum Academic Subject Categories
Rather than event labels, the talks in the VT-SSum dataset fall under broad academic disciplines and lecture domains inherent to VideoLectures.NET:

*   **Computer Science:** Machine Learning, Artificial Intelligence, Robotics, Databases, Software Engineering.
*   **Mathematics:** Statistics, Data Analysis, Algebra, Calculus, Applied Mathematics.
*   **Physics & Engineering:** Quantum Mechanics, Electrical Engineering, Material Sciences.
*   **Biology & Medicine:** Genetics, Oncology, Bioinformatics, Neuroscience.
*   **Social Sciences & Humanities:** Philosophy, Economics, Linguistics, Political Science.

### VT-SSum Dataset Specifications
*   **Total Videos:** 9,616 (divided into 7,692 train, 962 validation, 962 test)
*   **Total Samples:** ~125,000 transcript-summary pairs
*   **Target Modality:** Text-only transcripts (derived from automatic speech recognition with sentence alignment).
*   **Ground Truth:** Binary extractive labels ($0$/$1$) per sentence, weakly supervised by the corresponding lecture slide content (sentences that heavily match slide text are labeled as $1$ - summary worthy).

## 3. Dataset Format Differences Summary

| Feature | TVSum50 | VT-SSum |
| :--- | :--- | :--- |
| **Primary Domain** | User-generated web clips (YouTube) | Academic and scientific lectures (VideoLectures.NET) |
| **Task Type** | Visual frame/shot selection | Transcript segmentation & sentence extraction |
| **Ground Truth Format** | Frame/shot importance score array | Binary sentence-level labels (`label: 0` or `1`) |
| **Text Component** | video title only | full transcribed spoken text divided into segments |
