# Final Multimodal Video Summary

The presentation introduced the scope of the "Digital Cultural Heritage Library for Europe," a project funded by the European Commission, which aggregates four million digital cultural heritage objects and holds 26 million items spanning pictures, manuscripts, and recordings. The core focus of the discussion was not content management, but rather addressing challenges in multilingual information access and user behavior within this large collection.

The speakers explored the complexities of serving a global audience, distinguishing between the language of an image and the language of its metadata. Analysis of user behavior indicated that a majority of European users search in their native language, highlighting localization challenges where the collection content does not always align with all regional native languages. Significant technical hurdles were identified concerning the interface, as while the platform offers localization in 31 languages, translating dynamic content remains a substantial resource challenge. Furthermore, users exhibited confusing search behavior, often switching the interface language after performing a search in a different language, leading to unexpected results.

The discussion then shifted to the difficulties of multilingual search and document translation. A key challenge involves filtering query results based on language, particularly since the content language differs from the metadata language, necessitating clear categories for content types like music. Practical translation systems often struggle with accuracy, as general machine translation tools frequently produce errors when translating entire sentences, complicating the management of multilingual data.

To improve searchability and overcome data sparsity issues—where minimal input yields poor results—the team proposed semantic enrichment. This technique involves augmenting existing metadata with concepts from external vocabularies (such as the Gemma Thesaurus) to allow users to search records in multiple languages. This enrichment helps users find related objects even when data is sparse or ambiguous, such as resolving linguistic overlaps that cause confusion in image searches.

To address translation difficulties and context ambiguity, the system suggests adopting a new linked data model. This model connects specific vocabularies with multilingual sources, enabling the system to utilize domain-specific terminology while incorporating broader multilingual data. Finally, the presentation promoted the Sup Anna European project, an open data initiative, which provides free access to the heritage objects and offers tools for evaluating the effectiveness of semantic enrichment systems.
