This talk is about how to use machine learning for stock selection to form a profitable portfolio. Can we observe the fact that you know the larger the portfolio then the diversified the more diversified other stocks in the portfolio, so therefore the lower the average return? Is that is our method better than some of the previous methods? But basically the method is a modified competitive learning and K nearest neighbor combination, improved for the noisy and imbalance. So the objective is to use machine learning method to select a small number of good stocks to form a portfolio. Given information, the stock information prior to week T, can we predict the performance of stocks of week T so you know have previous information, pretty future one, and the training data set actually consists of following some of the previous works and experiments. Well, prototype ranking is a specially designed machine learning algorithm for noisy an imbalanced stock data. So in this algorithm there are components that specific design for stock data. The process contained 2 steps. In the first step, the algorithm tried to find good prototypes in the training data. To find those prototypes, we use competitive learning. I won't go through details, but after you run through those competitive learning you will be able to find some hidden density in the training data by those prototypes. You can read the paper, but the idea is that you know we try to find people to build a prototype tree and then try to search the prototypes in the predictor space and then adjust prototypes in step three in the goal attributes space in order to deal with the imbalanced data.
