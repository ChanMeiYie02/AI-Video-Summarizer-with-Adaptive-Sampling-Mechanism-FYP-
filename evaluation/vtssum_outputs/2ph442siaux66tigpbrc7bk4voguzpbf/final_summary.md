# Final Multimodal Video Summary

The research aims to exploit buried organizational knowledge by generating semantic profiles to enhance organizational knowledge management. The core focus is defining and analyzing informal communication, specifically emails, to identify senders, recipients, and topics, thereby building detailed user profiles. This approach involves a threefold process: collecting features from communication data, generating user profiles based on those features, and utilizing these profiles within organizational systems for knowledge retrieval.

To collect features, the system examines various methods, including analyzing communication frequency, content-person relationships, and monitoring social media activities. Users are profiled using features such as geographical data, age, interests, social connections, and interactions, often employing binary or non-binary functions to determine similarity. The ultimate goal is to use these profiles for information retrieval, providing personalized recommendations and suggestions to users.

A key experimental phase involved collecting emails from a group of users to extract features like keywords, named entities, and concepts using tools such as Java Automatic Term Recognition. To evaluate the model, participants rated their perceived similarity to colleagues, and the study found that semantic concepts proved to be the most significant indicators for finding similar users when correlated with keywords and named entities.

The system then explored visualization methods, using tools like Simnet to create a radiograph of users and color-coded emails. This led to developing dynamic cluster visualizations that group individuals based on expertise. These visualizations demonstrated that while individuals span diverse areas, collaboration often occurs across different research fields rather than strictly within a single project group. The system allows users to search for topics, suggest experts, and analyze communication tag clouds, linking individuals based on shared content.

Looking forward, the team is focusing on improving the system by developing dynamic semantic user profiles and refining visualization tools, particularly by allowing users to freely move nodes in layouts. Future work includes connecting user profiles to linked open data and exploring new real-time network visualizations.

The discussion also addressed critical issues concerning data access and privacy. The team highlighted the necessity of robust user modeling and authentication to ensure that sensitive information is only visible to authorized users, addressing potential risks in organizational security. Furthermore, the research examined how to handle sensitive materials and the challenges of accessing private versus public emails. Ultimately, the work emphasizes semantic annotation of sources and careful management of user data to ensure secure and effective knowledge sharing.
