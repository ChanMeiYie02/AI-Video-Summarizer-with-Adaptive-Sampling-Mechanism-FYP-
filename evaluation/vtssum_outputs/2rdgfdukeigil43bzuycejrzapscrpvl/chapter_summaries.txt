**AI Summary:**
The presentation discusses methods for relation extraction (RE), focusing on moving beyond traditional supervised learning toward more clever, often unsupervised approaches.

**Traditional Methods:**
The traditional method involves supervised learning: defining relation types, manually labeling text instances, and training a machine learning model. However, this process is laborious and requires a significant amount of labeled data.

**Distant Supervision:**
One advanced method is distant supervision, which assumes a pre-existing knowledge base (schema) and a set of labeled text. Entries in the knowledge base are aligned with the text, treated as truth, and used to train a model to find new instances. The drawback is that these alignments can be brittle.

**Unsupervised Approach (Open Information Extraction):**
A radically different approach discards the schema entirely and uses unsupervised methods on unlabeled text. This involves using dependency parsers to identify verbs and their arguments, thereby defining relations. While this generates diverse relation strings, a challenge remains in determining the implicit relationship between different relation types. The solution proposed is to perform automatic schema discovery, perhaps through clustering, to define the structure of the knowledge base.
