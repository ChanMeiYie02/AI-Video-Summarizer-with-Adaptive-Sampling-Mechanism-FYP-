So our work is based on the Bayesian optimization framework, So what space optimization, the goal in Bayesian optimization is to maximize an unknown function by running a small set of experiment. So given those constraints, the problem is that we need to schedule when to start new experiments and which ones to start. The challenging part is to manage this tradeoff between these two conflicting objectives. So we present both online and offline scheduling algorithm that effectively achieves this tradeoff.
