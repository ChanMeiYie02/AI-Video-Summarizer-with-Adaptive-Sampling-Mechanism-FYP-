# Final Multimodal Video Summary

The presentation introduced Kiwi, an EU-funded research project developed between 2008 and 2011, focused on creating a platform for semantic social media applications, evolving from a traditional knowledge wiki to a sophisticated enterprise knowledge management system. The core philosophy centered on moving away from rigid processes toward adaptable, social sharing models, prioritizing the ease of sharing ideas to maximize their power.

To address the challenges of managing diverse knowledge—including text, media, and software—Kiwi integrated Knowledge Management, Wiki philosophy, and the Semantic Web, enabling machine-readable linking of content. This approach allowed for flexible input and presentation across various data types, offering a low technological barrier for users.

The speaker then demonstrated the system’s implementation, a Java Enterprise Edition-based platform designed for project management and enterprise KM. The system features a semantic wiki that organizes content through automatic semantic data extraction, allowing users to view linked information, author details, and structured project planning details. Key features included advanced tagging systems that convert free text into conceptual tags and use ontologies to automatically generate rich RDF metadata, linking entities like locations and people.

The system incorporates a rule-based reasoner to derive new knowledge, such as identifying a resource as a meeting if it possesses both latitude and longitude coordinates. An administrative interface allows users to configure these rulesets, including specific models for reinforcement learning, providing powerful structured querying capabilities. Furthermore, the platform, Tagit, was shown to be versatile, offering features like geolocating content, faceted search for specific resources, and the ability to link media using RDF.

Ultimately, Kiwi is positioned as a comprehensive semantic application offering unified content access, advanced semantic tagging, and sophisticated querying. The application supports enterprise knowledge management, integration across systems, and public social media applications. The project’s technical stack is Java Enterprise Edition, built on a service-oriented architecture, and is open source. The discussion concluded by outlining potential pilot use cases and detailing plans to standardize APIs, ensuring the system remains extensible for future developers.
