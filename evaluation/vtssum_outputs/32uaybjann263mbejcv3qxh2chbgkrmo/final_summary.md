# Final Multimodal Video Summary

This presentation introduces a novel method for real-time 3D reconstruction and 6-Degrees-of-Freedom (6DOF) tracking using an event camera, developed in collaboration with Doctor Steven Leutenegger and Professor Andrew Davison. The core technology leverages event cameras, which report changes in light intensity rather than full frames, offering extremely high temporal resolution and detailed spatial information without motion blur, leading to significant reductions in power consumption and processing time.

The research addresses the challenge of Simultaneous Localization and Mapping (SLAM) by utilizing the stream of events instead of traditional image sequences. A key principle established is that events are generated based on the adaptive product of a motion vector and a gradient vector, providing an essential mechanism for tracking motion. The system’s primary goal is to move beyond planar mapping to create full 3D maps of unknown scenes.

The proposed architecture is divided into tracking and mapping components. It achieves 6DOF motion tracking by estimating camera pose using intensity differences and calculating motion vectors. Crucially, depth estimation is performed by analyzing the difference in event rates: closer objects generate a higher event rate, which provides accurate depth information. The system integrates a 3D coupled probabilistic filter and an intensity reconstruction block to establish a projective reference frame and estimate depth.

The methodology successfully demonstrated real-time operation on standard hardware, proving effective at estimating gradient intensity and depth across various dynamic scenes. The system can create semi-dense 3D point clouds from keyframes and is robust to movement, enabling it to create new keyframes and propagate estimates to maintain extended coverage. This approach offers a practical solution for SLAM-enabled products by enabling fast, motion-tracked tracking without the limitations of standard cameras.
