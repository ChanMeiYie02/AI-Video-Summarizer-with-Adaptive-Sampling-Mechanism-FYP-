# Final Multimodal Video Summary

The video introduces the concept of reasoning in knowledge graphs (KGs) using embeddings, defining KGs as nodes and relations, and the task of knowledge graph completion, which involves predicting missing relationships. The core focus shifts to performing complex reasoning over KGs, specifically multi-hop, path queries, and conjunctive queries, utilizing embeddings to enable prediction.

The system is demonstrated using a biomedical knowledge graph involving drugs, diseases, and proteins, illustrating how to answer complex queries. Two main types of queries are discussed: one-hop queries, which involve predicting missing links, and path queries, which chain multiple relations to find a final answer. A path query is structured by defining an anchor entity and a sequence of relationships to define a traversal path, such as finding proteins associated with adverse events caused by a drug.

A significant challenge is the inherent incompleteness of knowledge graphs, as many crucial relationships are missing, making simple traversal insufficient. While standard knowledge graph completion (KGC) addresses this by assigning probabilities to missing links, it significantly increases computational complexity. To tackle this, the speaker proposes the concept of predictive queries. This approach implicitly imputes or completes the knowledge graph to allow the system to answer any path query without requiring explicit edge imputation. This generalizes the standard link prediction task into a multi-step prediction task. Ultimately, the system reformulates the task of answering queries by focusing on predicting the specific entities that serve as the answer to the given query.
