# Final Multimodal Video Summary

The video begins by introducing Knowledge Graph Completion (KGC) methods such as TransE, TransR, DistMul, and ComplEx, focusing on the task of predicting the missing tail entity given a head node and a relation type. The foundational TransE model operates by learning shallow node embeddings such that the sum of the head embedding and the relation vector approximates the tail embedding ($h + r \approx t$). The training objective minimizes the distance between this calculated $h+r$ and the true tail entity.

The discussion then explores the expressive power of these models by examining different relational patterns. While TransE can model inverse relations by using the negative of the vector, and anti-symmetric relations through transitivity, it is limited. Specifically, TransE fails to model symmetric relations and struggles with one-to-N relationships because it embeds all entities into a single space, making distinct entities indistinguishable.

To overcome these limitations, the ColdTransR method is introduced. This approach addresses the constraints of TransE by creating a relation-specific space for each relation. ColdTransR utilizes a relation-specific projection matrix to map entities into a tailored space before applying the relation vector, successfully enabling the model to capture symmetric relations and one-to-N relations. Although this provides significant improvements, the method faces compositional limitations, struggling to model complex relationships.

Further exploring alternative scoring functions, the discussion introduces SRMMET, which uses a bilinear model to score relationships. Multimodal understanding is defined by cosine similarity between vectors, which defines a hyperplane in the embedding space. While complex embeddings offer a path to modeling various relational types—including using the complex conjugate for antisymmetric relations and setting the imaginary part to zero for symmetric relations—these methods still share limitations, failing to model composition or one-to-many relations effectively.

In conclusion, the choice of knowledge graph embedding method depends entirely on the structure of the relationships being analyzed. For instances involving one-to-many relations, methods like TransE should be avoided in favor of composite relations, emphasizing the trade-off between simplicity and the expressive power required to model specific relational patterns.
