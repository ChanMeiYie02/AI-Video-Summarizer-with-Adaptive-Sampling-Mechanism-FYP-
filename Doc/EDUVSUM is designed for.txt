EDUVSUM is designed for:

🎥 Educational video summarization
📚 Lecture / tutorial video analysis
🧠 Selecting important learning segments
📊 Training and evaluating video summarization models

It focuses on:

Key concepts in lectures
Important teaching moments
Structured learning content (slides, explanations, examples)

https://github.com/VideoAnalysis/EDUVSUM
EDUVSUM Dataset


-------------------------------------------------------------------------
TVSum is an extractive video frame , it is not for text summarization.
Video
  ↓
Frame features
  ↓
Model predicts importance scores
  ↓
Select top-ranked segments (summary)
  ↓
Compare with TVSum human importance scores
  ↓
Compute F-score / ranking correlation

If you end up using the dataset, we ask you to cite the following paper:
Yale Song, Jordi Vallmitjana, Amanda Stent, Alejandro Jaimes.
"TVSum: Summarizing Web Videos using Titles," IEEE CVPR 2015
